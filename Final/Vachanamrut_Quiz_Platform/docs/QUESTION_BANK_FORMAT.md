# Question Bank Format Guide

The application uses only questions and answers in the uploaded source file.

## 1. Multiple Choice Questions

```text
5. Multiple Choice Questions

1. Which option is correct?
A. First option
B. Second option
C. Third option
D. Fourth option
જવાબ: B
```

Student form: radio buttons. A wrong answer shows a red cross and is added to Revision.

## 2. Multiple Select Questions

```text
6. Multiple Select Questions

1. Select all correct options.
A. First
B. Second
C. Third
D. Fourth
જવાબ: A, C
```

Student form: checkboxes.

## 3. True or False

```text
7. True or False

1. Write the statement here.
જવાબ: સાચું
```

Student form: `સાચું` and `ખોટું` options.

## 4. Fill in the Blanks

```text
6. Fill in the Blanks

1. Complete the sentence: ________
જવાબ: Exact answer from the source
```

Student form: one-line written answer and **View Answer**.

## 5. One-word / Rapid Fire

```text
8. One-word Answer Questions

1. Write the question.
જવાબ: One word
```

Student form: one-line written answer and **View Answer**.

## 6. Very Short and Short Answer

```text
9. Very Short Answer Questions

1. Write the question.
જવાબ: Exact answer from the source

10. Short Answer Questions

1. Explain the point.
મોડેલ જવાબ: Full source answer shown to the student.
```

Student form: written answer box and **View Answer**.

## 7. Match the Following

```text
11. Match the Following

1. Item one | A. Match one
2. Item two | B. Match two
સાચી જોડણી
1-A
2-B
```

## 8. Arrange in Correct Sequence

```text
12. Arrange in Correct Sequence

Sequence 1
1. First item
2. Second item
3. Third item
સાચો ક્રમ
2, 1, 3
```

## Important rules

- Put the answer immediately after each question.
- Do not leave an answer blank.
- Keep each chapter in the correct destination chapter.
- Review the import preview before importing.
- Questions marked `Needs Review` are skipped.
